SEELENWANDERER – 16-BIT FAN EDITION

Zum Spielen auf dem iPhone die index.html auf einer Webseite wie GitHub Pages bereitstellen und den Link in Safari öffnen.
Eine Dateivorschau in ChatGPT oder Dateien startet HTML-Spiele nicht immer.

Anleitung: README.md in diesem Ordner.

START: Im Hochformat auf „JETZT SPIELEN“ tippen; im Querformat A drücken.
D-Pad: Bewegung; A: Aktion; B: Abwehr/Bremse.
Piste: Gas wird automatisch gegeben, B bremst.

Vollständiger Spielablauf plus Geheimweg enthalten.
